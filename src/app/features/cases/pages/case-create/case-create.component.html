Datos del incidente

¿Cómo registrar un caso?

  1. Ingresa la fecha, lugar y tipo de incidente.
  2. Describe la situación con hechos concretos.
  3. Agrega los estudiantes involucrados.
  4. Asigna un responsable de seguimiento.
  5. El caso se crea con estado “Reportado”.
Confidencialidad
La información registrada es confidencial y solo será visible para personal autorizado.
